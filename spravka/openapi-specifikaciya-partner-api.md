# OpenAPI спецификация Partner API

Машиночитаемая спецификация Partner API: [openapi-partner.yaml](../openapi-partner.yaml).

Partner API — server-to-server поверхность для платформ и CRM-систем: подключить
мерчанта в ApiPay программно и выставлять счета от его имени. После онбординга
мерчант получает собственный API-ключ, которым и выполняются платёжные операции.

Описание сценариев, параметров и примеров — в разделе
[Partner API](../docs/ru/partner-api.md).
