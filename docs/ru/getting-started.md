# Начало работы

## Подготовка

Для использования API ApiPay.kz:

1. **Зарегистрируйтесь** на [apipay.kz/login](https://apipay.kz/login)
2. **Подключите кассира Kaspi самостоятельно** — мастер в кабинете: [apipay.kz/connect-cashier](https://apipay.kz/connect-cashier) (Настройки → Авторизация Kaspi). Занимает 2–3 минуты: добавьте номер сотрудника с ролью **«Кассир»** в приложении Kaspi Pay (Настройки → Сотрудники), введите этот номер в мастере и подтвердите код из SMS. Подключение происходит сразу. Подробная инструкция — [гайд «Как подключить свою Kaspi-кассу»](https://apipay.kz/guides/podklyuchenie-kassira-kaspi).
3. **Получите API ключ** в Настройки → Подключение

> **Важно:** после привязки не входите в приложение Kaspi Pay под номером кассира — сессия разорвётся и кассира придётся подключать заново.
>
> Если мастер не проходит, поможем вручную: [WhatsApp поддержки (+7 700 307 65 12)](https://wa.me/77003076512).

## Конфигурация

| Параметр | Значение |
|----------|----------|
| Base URL | `https://api.apipay.kz/api/v1` |
| Аутентификация | Заголовок `X-API-Key: your_api_key` |
| Content-Type | `application/json` |
| Rate Limit | 200 запросов/минуту на API-ключ. Отдельные эндпоинты: `POST /clients/check` — 60/мин и 10 000/сутки, `POST /invoices/qr` — 60/мин на организацию, `GET /invoices/{id}` — 1000/мин, `POST /invoices/bulk` — 20/мин, `POST /catalog/scan` — 30/мин и 2000/сутки |

## Первый счёт

```bash
curl -X POST https://api.apipay.kz/api/v1/invoices \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"amount": 10000, "phone_number": "87001234567"}'
```

Ответ:
```json
{
  "id": 124,
  "amount": "10000.00",
  "status": "processing",
  "phone": "87001234567",
  "created_at": "2026-01-15T10:00:00+00:00"
}
```

Клиент получит уведомление в приложении Kaspi и сможет оплатить.

## Верификация бизнеса

При старте в рабочем режиме мы один раз просим заполнить короткую анкету «Расскажите о вашем бизнесе» (~5 минут в кабинете, `/business-profile`): что продаёте, где продаёте, примерный средний чек. Данные из анкеты нужны, чтобы настроить лимиты под ваши обороты.

Пока анкета не одобрена, действует осторожный старт: **1 реальный счёт в сутки** (в песочнице этот суточный лимит не действует — тестируйте в пределах квоты песочницы). При превышении API вернёт `429 kyc_daily_limit_reached` (в `meta.reset_at` — когда лимит сбросится). Одобрение обычно занимает **1 рабочий день**, после чего лимит снимается автоматически.

Дополнительно: для ещё не одобренных организаций рабочий webhook должен быть на реальном домене — IP и туннели (ngrok) отклоняются (см. [Webhooks](webhooks.md)).
