# Partner API OpenAPI Specification

The machine-readable Partner API specification: [openapi-partner.yaml](https://github.com/bazarbaykz/apipay-docs/blob/main/openapi-partner.yaml).

The Partner API is a server-to-server surface for platforms and CRM systems: onboard a
merchant into ApiPay programmatically and issue invoices on their behalf. Once onboarding
is done, the merchant gets an API key of their own, and payment operations run on that key.

Scenarios, parameters and examples are described in
[Partner API](../partner-api.md).
